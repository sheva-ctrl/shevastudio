# Sheva Studio

Sheva Studio Intros and How-Tos — a small site for learning AI and building ADHD-friendly content, without the jargon.

**Live at:** [shevastudio.com](https://shevastudio.com)

## Pages

| Page | What it does |
|---|---|
| `index.html` | Home — the hub linking to everything below |
| `Sheva-Studio-Intro-to-AI.html` | Start using AI today — the starter guide, prompt basics, tool picker |
| `guides.html` | Quick-glance prompt frameworks — the 5-step workflow and prompt recipe, at a glance |
| `prompt-builder.html` | Interactive tool — fill in Goal/Context/Audience/Format/Check and get a copy-ready prompt |
| `no-brainer-decks.html` | Pre-made ADHD challenge carousels — grab the slides, post them |
| `card-flip-generator.html` | Build your own dark/light carousel decks — editable, exportable as PNG |
