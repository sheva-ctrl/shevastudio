01 · The Big Idea

An agent is just a handoff that repeats.

Forget the sci-fi. Strip away the buzzword and an "agent" is something simple: instead of asking AI to do a task once, you set it up so it does that task again and again — with less and less input from you.

A prompt

You ask once. You get one answer. You start over next time.

A saved handoff

You save the instructions so you're not retyping them every time.

A multi-step handoff

One request triggers several steps — draft, check, format — in a row.

An agent

It knows your context, runs the steps, and only checks in when it needs you.

The through-line:
Every level is the same skill you already have — handing off. An agent just means you set it up once so you stop asking from scratch.
02 · What Every Agent Needs

Three ingredients. That's it.

Whether you build it in Copilot, a custom GPT, a Claude Project, or a Gemini Gem — every agent, at any level, comes down to these three.

A
A job — what it does, every time

"Turn my meeting notes into a summary and action items." One clear, repeatable task.

B
Context — what it always needs to know

Who you are, your format, your tone, your rules. Set once, so you never re-explain.

C
A trigger — when it runs

You paste something in, say a keyword, or (more advanced) it kicks off on a schedule.

In the room

Think of one handoff you already do. Say it out loud as a "job." Got it? You've done the hardest part.

03 · Where You Actually Build It

Three tiers. Pick your comfort level.

Same three ingredients, very different tools. Start wherever you are — you can always climb.

Tier 1 · No-code — start here

Built into tools you already have. No coding, ready in about ten minutes. Match it to your ecosystem.

Custom GPTs (ChatGPT) Claude Projects Gemini Gems (Google) Copilot agents (Microsoft)

Why it's the right start: you set the instructions, upload a few files, and it remembers your context every time. That's a real agent.

Tier 2 · Low-code / business — connect your systems

For agents that touch multiple apps and run real business workflows. A visual canvas, but a real learning curve.

Microsoft Copilot Studio Power Automate n8n (open-source)

Why here: these link an agent to your email, CRM, files, and databases — with governance controls. At work, only connect what your organization approves.

Tier 3 · Developer — full control

Code-first, for engineering teams building custom, production-grade agents.

OpenAI Agents SDK Codex Cursor Claude Agent SDK

Worth knowing: even here, the idea's the same — job, context, tools. You're just writing it instead of clicking it.

One idea worth knowing: portable "skills."
A new open standard (SKILL.md) lets you write an agent's instructions once and reuse them across many tools. The takeaway isn't the file — it's that the skill you build isn't locked to one product.
In the room

Which tier fits you today — not where you think you "should" be? Most people start at Tier 1. That's exactly right.

05 · Keep These In Your Hands

More power means more care.

An agent does more on its own — so the guardrails from last session matter even more here.

Keep a human in the loop

The more steps it runs, the more you check the output before anything goes out.

Mind what it can touch

At work, only connect an agent to data and systems your organization approves.

Start supervised

Run it with you watching a few times before you trust it to run on its own.

Know how to stop it

Whatever you build, know how to pause or turn it off. You're always in control.

Rule of thumb:
Your intern got a promotion — not your job. More trust, earned gradually, always supervised.

08 · Keep Going

You built something. Now grow it.

  • Start at Tier 1: Custom GPTs, Claude Projects, Gemini Gems, or Copilot — whichever matches the tool you already use. Search its name plus "custom" or "project."
  • Build the context once: the time you spend telling it your role, tone, and rules pays back every single run.
  • Supervise, then loosen: watch it work a few times before you trust it to run on its own.
  • Climbing to Tier 2? Copilot Studio, Power Automate, and n8n connect agents to your real systems — with governance. Get IT involved early.
